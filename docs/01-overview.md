# 01 项目概述

## 1.1 项目背景

绿色债券（Green Bond）是专门用于支持符合环境可持续发展目标的项目融资工具。随着全球"双碰"目标推进，绿色债券规模快速扩大，但同时也出现了一些质量参差不齐的现象：

- 资金用途与绿色项目实际不匹配
- 环境效益披露缺乏量化指标
- 项目认证依据的标准不符合国家或国际通行规范
- 发行人存在"洗绿"（greenwashing）动机

传统的人工审计方式面临文档量大、标准繁多、判断主观性强等问题。本平台借助 RAG 技术，将绿色债券相关标准、案例和规范构建成可检索的知识库，并通过大模型生成带有证据链的核验结论。

## 1.2 核心名词

| 名词 | 解释 |
|------|------|
| 绿色债券（Green Bond） | 筹集资金专项用于符合环境效益的项目的债券 |
| 洗绿（Greenwashing） | 实际环保效益低于披露水平，或资金用途与绿色标签不符 |
| RAG | Retrieval-Augmented Generation，检索增强生成，先检索知识库再生成回复 |
| 证据链 | 核验结论对应的原文出处、规则条款和推理过程 |

## 1.3 目标用户

- 投资者与机构：评估绿色债券质量
- 证监会与审计机构：提高审计效率
- 债券发行人与承销商：自我核查与披露优化
- 高校研究与学生团队：绿色金融 + AI 应用实践

## 1.4 平台目标

1. 自动化：减少人工逐页审阅量
2. 可解释：每个风险点都能追溯到文档出处
3. 可审计：保留全流程日志与版本
4. 可扩展：支持国内外主要绿色债券标准
